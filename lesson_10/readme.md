Предварительно помещаем файлы тестов и папку с методами *pages_allure в папку, в которой доступен запуск pytest и allure.

Для запуска тестирования, нужно в терминале ввести команду:
pytest --alluredir allure_rezult, 
где pytest - команда запуска,
 --alluredir - аттрибут для создания папки с рузельтатом тестирования для allure
allure_rezult  - имя папки с результатами

Для запуска просмотра отчета ввести команду:
allure serve allure_rezult/
В результате в браузере, используемом как браузер по-умолчанию, откроется страница с отчетом от Allure
